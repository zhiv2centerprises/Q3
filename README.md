# Q3 — Android 3D Studio v0.1

Q3 is a mobile-first foundation for a professional 3D modeling and animation application.

## Included
- Android Gradle project using Kotlin DSL
- Android Gradle Plugin 9.0.1
- Java 17 build environment
- Filament real-time rendering dependencies
- Touch-ready editor viewport foundation
- Outliner and object selection
- Scene entries for mesh, camera and light objects
- Timeline foundation
- Settings and About screen
- Copyright © Qazi Hissam Ud Din
- GitHub Actions workflow that builds and uploads a debug APK

## Cloud APK build
See `BUILD_ON_GITHUB.md`.

## Important
This is the Q3 foundation build, not a complete Blender replacement yet. The next engineering layers are real Filament geometry rendering, procedural primitives, transforms/gizmos, project serialization, storage import/export, mesh editing, materials/textures, animation/armatures, physics, offline rendering and video export.
